# KỊCH BẢN DEMO (5–7 PHÚT)

1. Giới thiệu mục tiêu: nhập JSON, phân tích và gửi Telegram.
2. Chạy `python main.py`; giới thiệu bốn thẻ số liệu và ba biểu đồ.
3. Mở tab Danh sách cảnh báo; tìm từ khóa `SSH`.
4. Chọn mức độ `Cao`; chọn agent `WEB-SERVER`.
5. Nhấp đúp một dòng để xem dữ liệu gốc.
6. Bấm Nhập file JSON và chọn `data/sample_alerts.json`; giải thích dữ liệu trùng không được lưu lại.
7. Giới thiệu `config.yml`; Telegram mặc định tắt để demo an toàn.
8. Chạy `python -m unittest discover -s tests -v`; kết thúc với kết quả 8/8 test đạt.

## Dự phòng

Nếu mất Internet, demo toàn bộ phần JSON, SQLite, bảng và biểu đồ. Không bật Telegram bằng token thật trong video công khai.
